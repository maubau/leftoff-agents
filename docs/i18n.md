# Languages

English (default), Italian, German, French, Spanish, Portuguese. Set `language` in `config.yaml`, or send `/language it` in chat.

## Where the words live

- `src/i18n/types.ts` — the contract: every sentence Leftoff says on its own, with the
  parameters it takes. Sentences with names or numbers are functions, because order and plurals
  differ by language.
- `src/i18n/{it,en,de,fr,es,pt}.ts` — one catalog per language, typed `Messages`: **the compiler
  refuses a language that lacks an entry**. `index.ts` registers them and knows each language's
  locale for dates and weekdays.
- `src/i18n/commands.ts` — chat commands in every language's own words (`/language`, `/lingua`, `/sprache`,
  `/langue`, `/idioma`…) and their arguments. `src/hub/approval.ts` holds the «yes»/«no» lists of
  all languages together: a fixed, closed set, never the model's judgement (D-022).
- `src/web/public/i18n.js` — the panel's own dictionary, with English as the fallback for any key
  a language lacks. The panel's language is chosen per device (localStorage), defaulting to the hub's.

## What follows which language

| | Follows |
|---|---|
| Alerts, stand-up, drafts, limits, restarts, command replies | the hub language: `language` in config, or `/language` (kept in the hub state) |
| The PM's free-form answers | the language the owner writes in; with no clue, the hub language (it is given with every question) |
| Instructions the hub writes to agents («resume now…», «send a report…») | the hub language |
| Control panel | the viewer's choice on that device |
| Technical tool results the model reads | English, always |

## Adding a language

1. Add its code to `LANGUAGES` and a locale to `LOCALES` in `src/i18n/index.ts`, and its names to
   `parseLanguage`.
2. Copy `en.ts` to `<code>.ts` and translate; `npm run typecheck` lists anything missing.
3. Add its yes/no words to `approval.ts`, its command words to `commands.ts`, and its dictionary to
   `src/web/public/i18n.js`.
4. `npm test`: `test/i18n.test.ts` fails if the catalog is incomplete, produces broken text, or is
   still a copy of English.

## Voice

Spoken replies use the Deepgram Aura-2 voice in `voice.speak.model`, which is Italian by default.
For another language choose a voice of that language; the text of the answer is always sent first.
