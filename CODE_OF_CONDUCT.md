# Code of conduct

This project is for people who want to build and use useful software together. To keep it that way:

- Be respectful and assume good faith. Disagree about ideas, not about people.
- No harassment, discrimination, personal attacks, or publishing someone else's private information.
- Keep discussion on topic and constructive; critique code and designs, not the author.
- Newcomers are welcome. A question is never a bad question; a patient answer is the right one.

This applies in issues, pull requests, discussions and anywhere else the project is represented.

Maintainers may edit or remove comments, and close or lock threads, that break these rules, and may block repeat
offenders. To report a problem, use GitHub's private reporting on the repository (Security → Report a vulnerability,
marking it as a conduct report) or contact the maintainer through their GitHub profile.

This text is a short statement in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
